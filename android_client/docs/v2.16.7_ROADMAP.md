## 2. 数据库与数据契约规范 (Room Schema v5)

### 2.1 studios 实体定义
```kotlin
package com.gpdb.android.data.db.entities

import androidx.room.ColumnInfo
import androidx.room.Entity
import androidx.room.Index
import androidx.room.PrimaryKey

@Entity(
    tableName = "studios",
    indices = [Index(value = ["name"], unique = true)]
)
data class StudioEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,
    val name: String,
    @ColumnInfo(name = "name_zh")
    val nameZh: String? = null,
    @ColumnInfo(name = "description_zh")
    val descriptionZh: String? = null,
    @ColumnInfo(name = "logo_url")
    val logoUrl: String? = null,
    @ColumnInfo(name = "banner_url")
    val bannerUrl: String? = null,
    @ColumnInfo(name = "updated_at")
    val updatedAt: String? = null
)
```

### 2.2 物理自愈兜底机制 (ensureSchemaCompatibility)
在用户挂载外部第三方生成的 `GPDb.db` 时，在 Room 初始化前无损补全缺失的实体表与查询索引：
```sql
CREATE TABLE IF NOT EXISTS studios (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    name           TEXT NOT NULL UNIQUE,
    name_zh        TEXT,
    description_zh TEXT,
    logo_url       TEXT,
    banner_url     TEXT,
    updated_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_studios_name ON studios(name);
CREATE INDEX IF NOT EXISTS idx_episodes_studio ON episodes(studio_name);
```

## 3. UI 界面与交互重构规范

### 3.1 厂牌历史专栏大画幅卡片设计
- 采用 Material 3 `Surface` 打造柔和圆角卡片（`RoundedCornerShape(20.dp)`）；
- 左侧加入 3dp 渐变高光强调色竖线条；
- 顶部放置 `MenuBook` 典籍图标 + 「厂牌历史档案与风格深度解析专栏」标题 + `AssistChip` 深度解析标签；
- 正文使用自适应排版与 `SelectionContainer`，保证长达数千字的厂牌发展史可供用户随时自由复制与阅读。

### 3.2 影片档案页通栏与按钮矩阵
- **第一层**：双封面海报（正反两张）自适应水平展示，点击支持 Lightbox 手势无级缩放；
- **第二层**：电影主标题、中英双语信息、年份时长、分类片商导演胶囊；
- **第三层**：**核心操作按钮矩阵（Action Matrix Panel）**：BT4G 搜索、BFTV 搜索、Google 搜索、卡片分享、收藏状态切换平齐排布；
- **第四层**：**剧情简介（通栏展开）**：`TranslationSection` 独占全宽，提供大字距双语对照；
- **第五层**：出演演员横向滚动（`LazyRow`）与收录分集列表。
