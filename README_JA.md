## 📖 プロジェクト概要 (About GPDb)

**GPDb**（Gay Pornography Database Manager）は、**ゲイアダルト映像（Gay Adult Media）**のファンやコレクター向けに特化して開発された、**現代的な高機能オフラインデータベース管理システム**です。

**100% オフラインファースト（Offline-First）と完全なプライバシー保護を徹底**：
- **クラウド完全非依存**：メディアのメタデータ、俳優の身体プロファイル、ポスターキャッシュ、個人マークはすべてローカルの物理ディスクに完全保存。
- **純粋なスタンドアローン設計**：ユーザーアカウント不要、テレメトリー追跡なし、外部サーバーへのアップロード一切なし。
- **圧倒的なネイティブ性能**：**Rust 高性能コア (`gpdb-core`)** + **Tauri v2 + Vue 3**（macOS / Windows）および **Kotlin + Jetpack Compose + Room**（Android ネイティブ）を基盤に、**63,000本以上の映画、134,000以上のシーン、108,000人以上の俳優、2,400以上のスタジオ**に対しても、滑らかな 60fps 描画とミリ秒単位の即時検索を実現。

## ✨ 主要機能ハイライト (Core Highlights)

- **きめ細やかな体貌フィルタリング**：体型・ビルド（Build）、髪色、瞳の色、体毛の濃さ、身長・体重、肌の色、生理サイズ（ペニスサイズ / 包茎状態）、タトゥー・ピアスの複合条件絞り込みに対応。

- **長編映画と独立シーンの精密な分離**：主演長編映画とゲスト出演短編シーンを明確に区別。
- **高耐障害性・複合検索**：FTS5 高速インデックス + SQL 複数フィールドフォールバックにより、中英バイリンガル、スタジオ、監督、あらすじ、出演者の多次元複合検索に対応。
- **PBC 百科全次元統合**：Porn Base Central 百科アーカイブを統合（本名、デビュー年、活動状況、略歴、IAFD/IMDb/X 連携リンク）。

### 3. スマートシリーズ集約とカバーコラージュ

### 💻 開発者向けビルドガイド (Developer Guide)

```bash
# 1. macOS デスクトップ版
cd desktop_client && npm install && npm run tauri dev      # ローカル開発
npm run tauri build                                         # プロダクションビルド (.app / .dmg)

# 2. Windows デスクトップ版
cd Windows_client && npm install && npm run tauri dev      # ローカル開発
npm run tauri build                                         # プロダクションビルド (.exe)

# 3. Android ネイティブ版
cd android_client && ./gradlew assembleRelease              # 署名済み Release APK のビルド

# 4. リリース前自動検証スクリプト
./git_tasks/pre_release_check.sh                            # パス整合性、プライバシー漏洩、バージョン整合性の検証
```
