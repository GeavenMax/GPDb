### 💻 開発者向けローカルビルド手順 (Developer Guide)

#### 動作環境
- **Node.js**：20以上 および npm
- **Rust**：1.78以上（`rustup`、`cargo`）
- **Android SDK**（Android 端のみ必要）：Android Studio Hedgehog 以上 または JDK 17以上

#### 1. macOS デスクトップ端の開発とビルド
```bash
# 1. リポジトリをクローン
git clone https://github.com/GeavenMax/GPDb.git
cd GPDb

# 2. デスクトップクライアントディレクトリに移動
cd desktop_client

# 3. フロントエンド依存パッケージのインストール
npm install

# 4. 開発モードでデスクトップクライアントを起動
npm run tauri dev

# 5. 本番リリース用アプリケーションをビルド（.app と .dmg を自動パッケージング）
npm run tauri build
```

#### 2. Windows デスクトップ端の開発とビルド
```powershell
# 1. Windows 専用クライアントディレクトリに移動
cd Windows_client

# 2. フロントエンド依存パッケージのインストール
npm install

# 3. 開発モードで起動
npm run tauri dev

# 4. 本番リリース用インストーラーをビルド（NSIS .exe インストーラーを生成）
npm run tauri build

# またはそのまま使えるビルドスクリプトを直接実行：
.\build_windows.ps1
```

#### 3. Android ネイティブモバイル端のコンパイル
```bash
# 1. Android ネイティブ端ディレクトリに移動
cd android_client

# 2. デバッグテスト用 APK をコンパイル
./gradlew assembleDebug

# 3. 本番署名済みリリース APK をコンパイル
./gradlew assembleRelease
```
